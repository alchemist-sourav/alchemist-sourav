## About

I'm Sourav, an Artificial Intelligence & Data Science engineering student and developer from Kerala, India. I enjoy taking ideas from prototype to working software — especially in AI-powered applications, backend systems and modern web experiences.

My work spans retrieval-augmented generation (RAG), LLM application security, AI-assisted workflows and full-stack product development. I value practical problem-solving, continuous learning and building software that is useful beyond a demo.

- **Current direction:** AI/ML engineering and full-stack development
- **Interested in:** LLM applications, RAG, AI agents, model evaluation and automation
- **Also enjoy:** UI/UX, open-source communities and developer tooling
